## Usage

To use PureConfig in an existing SBT project with Scala 2.13 or a later version, add the following dependency to your
`build.sbt`:

```scala
libraryDependencies += "com.github.pureconfig" %% "pureconfig" % "0.17.10"
```

For Scala 3, add the following dependency to your `build.sbt`:

```scala
libraryDependencies += "com.github.pureconfig" %% "pureconfig-core" % "0.17.10"
```
