## Installation

To install, follow these steps:

1. Clone the repository:
   ```sh
   git clone
   ```
2. Navigate to the project directory:
   ```sh
   cd Flame
   ```
3. Create conda environment:
   ```sh
   conda env create -f environment.yml
   conda activate flame
   ```
4. Install the node dependencies:
   ```sh
   npm install
   ```
