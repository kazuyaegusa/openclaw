## Installation

**Requirements**:

- Python >= 3.10
- PyTorch >= 2.0

Install GPyTorch using pip or conda:

```bash
pip install gpytorch
conda install gpytorch -c gpytorch
```

(To use packages globally but install GPyTorch as a user-only package, use `pip install --user` above.)
