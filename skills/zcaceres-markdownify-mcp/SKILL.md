# Markdownify MCP Server

## Installation

1. Clone this repository
2. Install dependencies:
   ```
   pnpm install
   ```

Note: this will also install `uv` and related Python depdencies.

3. Build the project:
   ```
   pnpm run build
   ```
4. Start the server:
   ```
   pnpm start
   ```
